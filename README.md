# Jewels by Iram

A stunning, responsive website for **Jewels by Iram** — an exquisite handcrafted jewellery brand.

## Features

- **Hero Section** — Full-screen image slider showcasing jewellery with elegant brand logo
- **About Section** — Brand story with model imagery and animated stats
- **Collections Gallery** — Filterable grid (Necklaces, Earrings, Jewellery Sets) with lightbox preview
- **Lookbook** — Masonry-style model photography grid with hover effects
- **Contact Section** — Contact form with floating labels and social links
- **Fully Responsive** — Optimized for mobile, tablet, and desktop
- **Smooth Animations** — Scroll-reveal effects, parallax banners, and counter animations

## Getting Started

Simply open `index.html` in a web browser — no build tools or server required.

```bash
# Clone and open
git clone https://github.com/jubin-ts/jewels-by-iram.git
cd jewels-by-iram
open index.html    # macOS
# or: start index.html  # Windows
# or: xdg-open index.html  # Linux
```

## Technologies

- Pure HTML5, CSS3, JavaScript (no frameworks)
- Google Fonts (Cormorant Garamond + Montserrat)
- CSS Grid & Flexbox layouts
- Intersection Observer API for scroll animations
- CSS custom properties for theming
